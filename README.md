# Seios em Harmonia — Landing page

Página estática. Publicação no GitHub Pages:

1. Envie todo o conteúdo desta pasta para a raiz do repositório (`index.html`, `support.js`, `img/`).
2. Settings → Pages → Source: `Deploy from a branch` → branch `main`, pasta `/ (root)`.
3. Acesse `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

Mantenha `support.js` e a pasta `img/` ao lado do `index.html`.
